# 引擎模块（以预编译二进制分发）

本目录下的业务引擎不随开源仓库发布源码：

| 模块 | 职责 |
|---|---|
| `ccb_api` | 平台业务接口封装 |
| `progress` | 学习进度心跳与点位算法 |
| `signer` / `sm3` | 请求签名 |
| `sync` | 课程/专题班拉取与落库 |
| `runner` | 会话生命周期、调度与并发 |

> 实际编译范围以 `release/engine.list` 白名单为准（v3.36 为上述 6 个纯刷课模块；考试相关模块未在本版发布）。

它们在发布镜像内以编译后的
`*.cpython-312-x86_64-linux-gnu.so` 形式存在，运行时被 Python 正常导入，
**使用 `docker compose`（拉取成品镜像）即可获得完整功能，无需也无法在此处本地构建引擎。**

源码编译流程见仓库 `release/`（`engine.list` 白名单、`compile_engines.py`、
`Dockerfile.app` 多阶段构建）。本仓库其余部分（路由、模型、前端、调度编排、
发版工具链）均为明文，可供学习与审计。
